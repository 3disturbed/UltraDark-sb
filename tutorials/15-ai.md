# Tutorial 15 — AI

**You will build:** enemies that patrol, notice you, chase, attack, and retreat
when hurt — built from a behaviour tree over a navmesh. **Time:** ~45 minutes.

Builds on [Tutorial 14](14-gameplay-framework.md).

---

## 1. The pieces

| Type | Role |
|---|---|
| `Blackboard` | typed key/value memory the tree reasons over |
| `BehaviorTree` + nodes | the decision logic |
| `NavMesh` / `NavMeshAgent` | pathfinding and steering |
| `AIController` | a `Controller` that ties them to a `Pawn` |

`AIController` derives from `Controller`, so **an AI possesses the same `Pawn` a
player would**. One character class, two brains.

## 2. Blackboard

Shared memory. Keep the keys in a `static class` — typos are silent failures.

`MyGame/AI/BB.cs`:

```csharp
namespace MyGame.AI;

public static class BB
{
    public const string Target     = "target";
    public const string Home       = "home";
    public const string Waypoint   = "waypoint";
    public const string FleeTo     = "fleeTo";
    public const string LastSeenAt = "lastSeenAt";
    public const string Alert      = "alert";
}
```

```csharp
using SexyBiscuit.Engine.AI;

var bb = new Blackboard();
bb.Set(BB.Target, playerActor);
bb.Set(BB.Home, spawnPosition);
bb.Set(BB.Alert, 0);

Actor? t = bb.Get<Actor>(BB.Target);
int alert = bb.Get(BB.Alert, fallback: 0);
if (bb.TryGet<Vector3>(BB.Home, out var home)) { }

// Resolves an Actor, a Transform3D, or a raw Vector3 to a world position.
if (bb.TryGetPosition(BB.Target, out var pos)) { }

bb.Has(BB.Target);        // false when absent OR null
bb.Clear(BB.Target);
bb.ClearAll();
bb.ValueChanged.Add(key => Debug.WriteLine($"blackboard {key} changed"));
```

`TryGetPosition` is the one you will use most: nodes can read a target's
location without caring how it was stored.

## 3. Behaviour tree basics

The tree ticks from the root each frame; every node returns:

```csharp
public enum NodeStatus { Success, Failure, Running }
```

`Running` means "not finished, tick me again" — how a tree expresses multi-frame
actions without coroutines.

### Composites

| Node | Semantics |
|---|---|
| `Sequence` | children in order; stops at the first `Failure`. **AND** |
| `Selector` | children in order; stops at the first `Success`. **OR / fallback** |
| `Parallel` | ticks all children; `SuccessThreshold` / `FailureThreshold` decide |

Both `Sequence` and `Selector` **remember their position across frames**: a
sequence whose third child returns `Running` resumes at that child next tick
rather than restarting.

### Decorators

| Node | Semantics |
|---|---|
| `Inverter(child)` | swaps `Success` ↔ `Failure` |
| `Succeeder(child)` | always `Success` |
| `Repeater(child, count = 0)` | repeats `count` times, or forever at `0`; `StopOnFailure` defaults true |
| `Cooldown(child, seconds)` | blocks the child until `seconds` since it last finished |
| `Condition(predicate, child)` | runs the child **only while** the predicate holds; resets and fails otherwise |

`Cooldown` is what stops an expensive or noisy behaviour retriggering every
frame. `Condition` is an *interrupting* guard — re-evaluated before every tick,
so "chase while you can see the target" stops the instant sight is lost.

### Leaves

```csharp
new ActionNode(c => { DoThing(); return NodeStatus.Success; }, "DoThing");
new ActionNode(c => DoThing(), "DoThing");            // void overload → always Success
new ConditionNode(c => Hp < 30, "LowHealth");
new WaitNode(1.5f);
new MoveToNode(BB.Target, acceptanceRadius: 2f) { Timeout = 15f };
```

`MoveToNode` reads a destination from the blackboard key you name, drives the
controller's `NavMeshAgent`, and returns `Running` while travelling, `Success` on
arrival, `Failure` on timeout or a failed path.

## 4. A navmesh

```csharp
using SexyBiscuit.Engine.AI;

NavMesh mesh = NavMesh.Build(vertices, indices);
NavMesh.Active = mesh;                  // agents default to this
```

There is no automatic bake — you supply geometry. For a flat arena, generate a
grid:

`MyGame/AI/NavMeshBuilder.cs`:

```csharp
using Microsoft.Xna.Framework;
using SexyBiscuit.Engine.AI;

namespace MyGame.AI;

public static class NavMeshBuilder
{
    /// <summary>Builds a flat grid navmesh, skipping cells the predicate rejects.</summary>
    public static NavMesh Grid(Vector2 min, Vector2 max, float cell, float y = 0f,
                               Func<Vector3, bool>? walkable = null)
    {
        var vertices = new List<Vector3>();
        var indices  = new List<int>();

        int cols = (int)MathF.Ceiling((max.X - min.X) / cell);
        int rows = (int)MathF.Ceiling((max.Y - min.Y) / cell);

        for (int r = 0; r < rows; r++)
        for (int c = 0; c < cols; c++)
        {
            float x0 = min.X + c * cell, x1 = x0 + cell;
            float z0 = min.Y + r * cell, z1 = z0 + cell;

            var centre = new Vector3((x0 + x1) * 0.5f, y, (z0 + z1) * 0.5f);
            if (walkable != null && !walkable(centre)) continue;

            int b = vertices.Count;
            vertices.Add(new Vector3(x0, y, z0));
            vertices.Add(new Vector3(x1, y, z0));
            vertices.Add(new Vector3(x1, y, z1));
            vertices.Add(new Vector3(x0, y, z1));

            indices.AddRange(new[] { b, b + 1, b + 2, b, b + 2, b + 3 });
        }

        return NavMesh.Build(vertices, indices);
    }
}
```

```csharp
NavMesh.Active = NavMeshBuilder.Grid(
    min: new Vector2(-40, -40),
    max: new Vector2( 40,  40),
    cell: 2f,
    walkable: p => !PhysicsSystem3D.Instance.Raycast(
                        p + Vector3.Up * 2f, Vector3.Down, 3f, out var hit)
                   || hit.Actor?.Tag != "Obstacle");
```

```csharp
mesh.TriangleCount;  mesh.Bounds;
mesh.SamplePosition(worldPoint, maxDistance: 3f, out Vector3 nearest);
mesh.IsStraightPathClear(from, to, stepLength: 0.5f, tolerance: 0.5f);

var corners = new List<Vector3>();
mesh.FindPath(start, goal, corners, snapDistance: 2f);

foreach (var (a, b, c) in mesh.EnumerateTriangles())
    Gizmos.DrawLine(a, b, Color.Lime);
```

**Draw the navmesh while you are building it.** "Why won't my agent go there" is
almost always a hole in the mesh, and `EnumerateTriangles` + `Gizmos` shows it
in one glance.

## 5. NavMeshAgent

```csharp
using SexyBiscuit.Engine.AI;

var agent = pawn.AddComponent<NavMeshAgent>();
agent.NavMesh               = NavMesh.Active;
agent.Speed                 = 3.5f;
agent.AngularSpeed          = 540f;
agent.StoppingDistance      = 0.4f;
agent.CornerTolerance       = 0.3f;
agent.RepathInterval        = 0.5f;
agent.SnapDistance          = 2f;      // how far off-mesh a request may start
agent.FaceMovementDirection = true;
agent.DriveCharacter        = true;    // feed AddMovementInput instead of moving the transform
```

```csharp
agent.SetDestination(target);
agent.ResetPath();
agent.SetPath(precomputedCorners);
agent.IsStopped = true;

agent.Path;  agent.CurrentCorner;  agent.Destination;
agent.RemainingDistance;  agent.HasReachedDestination;  agent.PathFailed;

agent.DestinationReached.Add(() => Debug.WriteLine("arrived"));
agent.PathfindingFailed.Add(() => Debug.WriteLine("no path"));
```

Set **`DriveCharacter = true`** when the actor is a `Character` — the agent then
feeds `AddMovementInput` instead of teleporting the transform, so physics,
gravity and animation stay in charge. `AIController.Possess` adds a
`NavMeshAgent` for you.

## 6. AIController

```csharp
using SexyBiscuit.Engine.AI;
using SexyBiscuit.Engine.Gameplay;

var pawn = new Character("Grunt") { WalkSpeed = 3.5f, OrientToMovement = true };
pawn.AddComponent<Transform3D>().Position = spawn;
scene.AddActor(pawn);

var ai = new AIController
{
    SightRadius        = 22f,
    FieldOfView        = 110f,      // full cone angle, degrees
    RequireLineOfSight = true,
    EyeHeight          = 1.6f,
    BrainEnabled       = true,
};
scene.AddActor(ai);
ai.Possess(pawn);                    // adds the NavMeshAgent
```

```csharp
ai.Blackboard;
ai.NavAgent;
ai.CanSee(target);         // radius + FOV + optional line-of-sight raycast
ai.MoveTo(position);  ai.MoveTo(actor);  ai.StopMovement();
ai.BrainEnabled = false;   // freeze the AI without destroying it
```

`CanSee` is your perception primitive: distance against `SightRadius`, angle
against `FieldOfView`, then an optional raycast from `EyeHeight`. Wire it into a
`Condition` decorator and the behaviour interrupts the moment sight breaks.

## 7. A complete enemy brain

`MyGame/AI/GruntBrain.cs`:

```csharp
using Microsoft.Xna.Framework;
using SexyBiscuit.Engine;
using SexyBiscuit.Engine.AI;
using SexyBiscuit.Engine.Core;
using SexyBiscuit.Engine.Gameplay;
using MyGame.Components;

namespace MyGame.AI;

public static class GruntBrain
{
    public static AIController Spawn(Scene scene, Vector3 position, Vector3[] patrol)
    {
        var pawn = new Character("Grunt") { WalkSpeed = 3.2f, OrientToMovement = true };
        pawn.AddComponent<Transform3D>().Position = position;
        pawn.AddComponent<Health>().Max = 60;
        scene.AddActor(pawn);

        var ai = new AIController { SightRadius = 22f, FieldOfView = 110f };
        scene.AddActor(ai);
        ai.Possess(pawn);

        ai.Blackboard.Set(BB.Home, position);
        int waypoint = 0;

        var health = pawn.GetComponent<Health>()!;

        var root = new Selector(

            // ---- 1. Flee when badly hurt ---------------------------------
            new Sequence(
                new ConditionNode(_ => health.Current < health.Max * 0.25f, "LowHealth"),
                new ActionNode(c => c.Blackboard.Set(BB.FleeTo, c.Blackboard.Get<Vector3>(BB.Home)),
                               "PickHome"),
                new MoveToNode(BB.FleeTo, acceptanceRadius: 1.5f),
                new WaitNode(4f)),                       // recover before re-engaging

            // ---- 2. Chase and attack what we can see ----------------------
            new Condition(
                c => c.Controller?.CanSee(c.Blackboard.Get<Actor>(BB.Target)) == true,
                new Sequence(
                    new ActionNode(c =>
                    {
                        // Remember where we last saw them, for the search below.
                        if (c.Blackboard.TryGetPosition(BB.Target, out var p))
                            c.Blackboard.Set(BB.LastSeenAt, p);
                    }, "RememberTarget"),
                    new MoveToNode(BB.Target, acceptanceRadius: 2f),
                    new Cooldown(
                        new ActionNode(c => Attack(c, 12), "Attack"),
                        seconds: 1.1f))),

            // ---- 3. Search the last known position ------------------------
            new Sequence(
                new ConditionNode(c => c.Blackboard.Has(BB.LastSeenAt), "HasLastSeen"),
                new MoveToNode(BB.LastSeenAt, acceptanceRadius: 1.5f),
                new WaitNode(2f),
                new ActionNode(c => c.Blackboard.Clear(BB.LastSeenAt), "ForgetLastSeen")),

            // ---- 4. Otherwise patrol --------------------------------------
            new Sequence(
                new ActionNode(c =>
                {
                    c.Blackboard.Set(BB.Waypoint, patrol[waypoint]);
                    waypoint = (waypoint + 1) % patrol.Length;
                }, "NextWaypoint"),
                new MoveToNode(BB.Waypoint, acceptanceRadius: 1f),
                new WaitNode(1.5f))
        );

        ai.BehaviorTree = new BehaviorTree(root, ai.Blackboard, ai);
        return ai;
    }

    private static NodeStatus Attack(BehaviorContext c, int damage)
    {
        var target = c.Blackboard.Get<Actor>(BB.Target);
        if (target == null || target.IsDestroyed) return NodeStatus.Failure;

        target.GetComponent<Health>()?.Damage(damage, c.Controller?.ControlledPawn);
        SBEngine.Instance.Audio.PlayOneShot("Assets/Audio/swing.wav");
        return NodeStatus.Success;
    }
}
```

Read the `Selector` top to bottom: *flee if hurt, else fight what you can see,
else search where you last saw them, else patrol*. That is exactly how it
behaves, and reordering the children reorders the priorities. That legibility is
the reason to use a tree rather than a pile of `if`s.

Feed it a target from your perception or damage code:

```csharp
ai.Blackboard.Set(BB.Target, player);
```

Or let each AI find one itself:

```csharp
public sealed class TargetFinder : Component
{
    public string  Tag      = "Player";
    public float   Interval = 0.5f;

    private AIController? _ai;
    private float _timer;

    public override void Start() => _ai = Actor as AIController;

    public override void Update(float dt)
    {
        if (_ai == null) return;
        _timer -= dt;
        if (_timer > 0f) return;
        _timer = Interval;

        var candidate = Actor.Scene?.FindByTag(Tag).FirstOrDefault();
        if (candidate != null && _ai.CanSee(candidate))
            _ai.Blackboard.Set(BB.Target, candidate);
    }
}
```

Half-second re-targeting rather than per-frame keeps the cost sane with dozens of
enemies.

## 8. Custom nodes

```csharp
using Microsoft.Xna.Framework;
using SexyBiscuit.Engine.AI;
using SexyBiscuit.Engine.Core;

namespace MyGame.AI;

/// <summary>Strafes around a blackboard target for a fixed duration.</summary>
public sealed class StrafeNode : BehaviorNode
{
    private readonly string _key;
    private readonly float  _seconds;
    private readonly float  _radius;
    private float _elapsed;
    private int   _sign = 1;

    public StrafeNode(string targetKey, float seconds = 2f, float radius = 4f)
    {
        _key = targetKey; _seconds = seconds; _radius = radius;
        Name = "Strafe";
    }

    protected override void OnEnter(BehaviorContext c)
    {
        _elapsed = 0f;
        _sign = SBMath.Random.Next(2) == 0 ? -1 : 1;
    }

    protected override NodeStatus OnTick(BehaviorContext c)
    {
        if (!c.Blackboard.TryGetPosition(_key, out var target)) return NodeStatus.Failure;

        var pawn = c.Controller?.ControlledPawn;
        var t3d  = pawn?.GetComponent<Transform3D>();
        if (t3d == null) return NodeStatus.Failure;

        _elapsed += c.DeltaTime;
        if (_elapsed >= _seconds) return NodeStatus.Success;

        var toTarget = target - t3d.Position;
        var tangent  = Vector3.Cross(SBMath.SafeNormalize(toTarget), Vector3.Up) * _sign;

        c.Controller!.MoveTo(target - SBMath.SafeNormalize(toTarget) * _radius + tangent * 2f);
        return NodeStatus.Running;
    }

    protected override void OnExit(BehaviorContext c, NodeStatus status)
        => c.Controller?.StopMovement();
}
```

`OnEnter` fires when the node starts or restarts; `OnTick` every tick; `OnExit`
when it returns a terminal status. `BehaviorContext` carries `Blackboard`,
`Controller` and `DeltaTime`.

```csharp
new Sequence(
    new MoveToNode(BB.Target, 5f),
    new StrafeNode(BB.Target, seconds: 2.5f, radius: 5f),
    new Cooldown(new ActionNode(c => Attack(c, 20), "Ranged"), 2f));
```

## 9. Squads with a shared blackboard

Two AIs can share one `Blackboard`, which gives you coordination for free:

```csharp
var squadBrain = new Blackboard();
squadBrain.Set("squadTarget", player);

foreach (var ai in squad)
    ai.BehaviorTree = new BehaviorTree(BuildRoot(), squadBrain, ai);
```

One member spotting the player writes `squadTarget`; every member reads it on
the next tick. Add roles by giving each AI a personal blackboard key and
consulting both.

## 10. Debugging

```csharp
using SexyBiscuit.Engine.Debug;

public sealed class AiDebug : Component
{
    private AIController? _ai;

    public override void Start() => _ai = Actor as AIController;

    public override void Update(float dt)
    {
        if (_ai?.NavAgent is not { } agent || !Gizmos.Enabled) return;

        // The current path
        for (int i = 1; i < agent.Path.Count; i++)
            Gizmos.DrawLine(agent.Path[i - 1], agent.Path[i], Color.Yellow);

        // The destination
        if (agent.Destination is { } d) Gizmos.DrawSphere(d, 0.4f, Color.Orange);

        // The sight radius, red when it can see its target
        var pawn = _ai.ControlledPawn?.GetComponent<Transform3D>();
        if (pawn != null)
        {
            bool sees = _ai.CanSee(_ai.Blackboard.Get<Actor>(BB.Target));
            Gizmos.DrawCircle(pawn.Position, _ai.SightRadius, 32,
                              sees ? Color.Red : Color.Gray);
        }

        // What the tree decided
        if (_ai.BehaviorTree is { } tree)
            Gizmos.DrawText(pawn?.Position ?? Vector3.Zero,
                            $"{tree.Root.Name}: {tree.LastStatus}", Color.White);
    }
}
```

`BehaviorNode.LastStatus` on each node tells you which branch ran. Walk the tree
once a second and log it while tuning:

```csharp
static void Dump(BehaviorNode node, int depth = 0)
{
    Debug.WriteLine($"{new string(' ', depth * 2)}{node.Name}: {node.LastStatus}");
    if (node is CompositeNode comp)
        foreach (var child in comp.Children) Dump(child, depth + 1);
    else if (node is DecoratorNode dec)
        Dump(dec.Child, depth + 1);
}
```

## 11. Performance

- **`BrainEnabled = false` for distant AI.** The cheapest optimisation available.

```csharp
public sealed class AiCulling : Component
{
    public float ActiveRadius = 60f;

    private AIController? _ai;
    private Actor?        _player;

    public override void Start()
    {
        _ai     = Actor as AIController;
        _player = Actor.Scene?.FindByTag("Player").FirstOrDefault();
    }

    public override void Update(float dt)
    {
        if (_ai?.ControlledPawn == null || _player == null) return;

        var a = _ai.ControlledPawn.GetComponent<Transform3D>()?.Position ?? Vector3.Zero;
        var b = _player.GetComponent<Transform3D>()?.Position ?? Vector3.Zero;

        _ai.BrainEnabled = Vector3.DistanceSquared(a, b) < ActiveRadius * ActiveRadius;
    }
}
```

- **Raise `RepathInterval`.** Half a second is plenty for most enemies;
  pathfinding is the expensive part.
- **Use `Cooldown` on expensive nodes** — line-of-sight sweeps, target scans.
- **Prefer `IsStraightPathClear` to `FindPath`** when the target is close: a
  straight-line check is far cheaper than A*.
