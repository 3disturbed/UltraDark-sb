# 23. AI

Namespace: `SexyBiscuit.Engine.AI`

Three cooperating pieces:

| Type | Role |
|---|---|
| `Blackboard` | typed key/value memory shared by a tree |
| `BehaviorTree` + nodes | the decision logic |
| `NavMesh` / `NavMeshAgent` | pathfinding and steering |
| `AIController` | a [`Controller`](22-gameplay-framework.md) that ties them to a `Pawn` |

Because `AIController` derives from `Controller`, an AI possesses the **same
`Pawn`** a player would. One character class, two brains.

---

## Blackboard

```csharp
var bb = new Blackboard();

bb.Set("target", enemyActor);
bb.Set("homePosition", spawnPoint);
bb.Set("alertLevel", 2);
bb.Set("isFleeing", false);

Actor? t = bb.Get<Actor>("target");
int level = bb.Get("alertLevel", fallback: 0);
if (bb.TryGet<Vector3>("homePosition", out var home)) { }
if (bb.TryGetPosition("target", out var pos)) { }        // Actor, Transform3D or Vector3

bool has = bb.Has("target");        // false when absent *or* null
bb.Clear("target");
bb.ClearAll();

bb.ValueChanged.Add(key => Debug.WriteLine($"blackboard {key} changed"));
foreach (var key in bb.Keys) { }
```

`TryGetPosition` is the useful one: it resolves an `Actor`, a `Transform3D` or a
raw `Vector3` stored under the key to a world position, so nodes can read a
target's location without caring how it was stored.

Keep blackboard keys in a `static class` of `const string`s — typos are silent.

## Behaviour trees

A tree ticks from the root each frame and every node returns a `NodeStatus`:

```csharp
public enum NodeStatus { Success, Failure, Running }
```

`Running` means "not finished, tick me again next frame", which is how a tree
expresses multi-frame actions without coroutines.

### Composites

| Node | Semantics |
|---|---|
| `Sequence` | children in order; stops at the first `Failure`. **AND** |
| `Selector` | children in order; stops at the first `Success`. **OR / fallback** |
| `Parallel` | ticks all children; `SuccessThreshold` / `FailureThreshold` decide the result |

```csharp
new Sequence(
    new ConditionNode(c => c.Blackboard.Has("target")),
    new MoveToNode("target", acceptanceRadius: 2f),
    new ActionNode(c => { Attack(); return NodeStatus.Success; }, "Attack"));
```

```csharp
var parallel = new Parallel(patrolNode, scanForEnemiesNode)
{
    SuccessThreshold = 1,     // succeed as soon as one child succeeds
    FailureThreshold = 1,
};
```

Both composites remember their position across frames: a `Sequence` whose third
child returns `Running` resumes at that child next tick rather than restarting.

### Decorators

| Node | Semantics |
|---|---|
| `Inverter(child)` | swaps `Success` ↔ `Failure` |
| `Succeeder(child)` | always reports `Success` |
| `Repeater(child, count = 0)` | repeats `count` times, or forever when `0`; `StopOnFailure` defaults to true |
| `Cooldown(child, seconds)` | blocks the child until `seconds` have passed since it last finished |
| `Condition(predicate, child)` | runs the child only while the predicate holds; resets it and fails when it turns false |

`Cooldown` is what stops an expensive or noisy behaviour — a shout, a special
attack, a re-path — from retriggering every frame.

`Condition` is an *interrupting* guard: it re-evaluates before every tick of the
child, so "chase while you can see the target" stops the moment sight is lost.

### Leaves

```csharp
new ActionNode(c => { DoThing(); return NodeStatus.Success; }, "DoThing");
new ActionNode(c => DoThing(), "DoThing");                 // void overload, always Success
new ConditionNode(c => Hp < 30, "LowHealth");
new WaitNode(1.5f);
new MoveToNode("target", acceptanceRadius: 1.5f) { Timeout = 15f };
```

`MoveToNode` reads a destination from the blackboard key you name (via
`TryGetPosition`), drives the controller's `NavMeshAgent`, returns `Running`
while travelling, `Success` on arrival, and `Failure` on timeout or a failed
path.

### Assembling a tree

```csharp
var bb = new Blackboard();
bb.Set("home", spawnPosition);

var root = new Selector(
    // 1. Flee when badly hurt.
    new Sequence(
        new ConditionNode(c => Hp < 25, "LowHealth"),
        new ActionNode(c => c.Blackboard.Set("fleeTo", SafeSpot()), "PickSafeSpot"),
        new MoveToNode("fleeTo", 1f)),

    // 2. Chase and attack a visible target.
    new Condition(c => c.Controller?.CanSee(c.Blackboard.Get<Actor>("target")) == true,
        new Sequence(
            new MoveToNode("target", acceptanceRadius: 2f),
            new Cooldown(
                new ActionNode(c => { Attack(); return NodeStatus.Success; }, "Attack"),
                seconds: 1.2f))),

    // 3. Otherwise patrol.
    new Repeater(
        new Sequence(
            new ActionNode(c => c.Blackboard.Set("waypoint", NextWaypoint()), "NextWaypoint"),
            new MoveToNode("waypoint", 1f),
            new WaitNode(2f))));

var tree = new BehaviorTree(root, bb, aiController);
```

```csharp
NodeStatus status = tree.Tick(dt);      // AIController does this for you
tree.Reset();
tree.Root;  tree.Blackboard;  tree.Context;  tree.LastStatus;
```

Order matters in a `Selector`: put the highest-priority behaviour first. The
tree above reads top to bottom as "flee if hurt, else fight what you can see,
else patrol", which is exactly how it behaves.

### Custom nodes

```csharp
public sealed class FaceTargetNode : BehaviorNode
{
    private readonly string _key;
    public FaceTargetNode(string key) { _key = key; Name = "FaceTarget"; }

    protected override void OnEnter(BehaviorContext c) { }

    protected override NodeStatus OnTick(BehaviorContext c)
    {
        if (!c.Blackboard.TryGetPosition(_key, out var target)) return NodeStatus.Failure;
        var pawn = c.Controller?.ControlledPawn;
        var t3d  = pawn?.GetComponent<Transform3D>();
        if (t3d == null) return NodeStatus.Failure;

        t3d.LookAt(target);
        return NodeStatus.Success;
    }

    protected override void OnExit(BehaviorContext c, NodeStatus status) { }
}
```

`OnEnter` fires when the node starts (or restarts after finishing), `OnTick`
every tick, `OnExit` when it returns a terminal status. `BehaviorContext` gives
you `Blackboard`, `Controller` and `DeltaTime`.

## NavMesh

```csharp
NavMesh mesh = NavMesh.Build(vertices, indices);
NavMesh.Active = mesh;              // agents default to this
```

```csharp
mesh.TriangleCount;
mesh.Bounds;                        // Bounds struct

// Nearest point on the mesh, within maxDistance.
if (mesh.SamplePosition(worldPoint, maxDistance: 3f, out Vector3 nearest)) { }
if (mesh.SamplePosition(worldPoint, 3f, out var p, out int triangleIndex)) { }

// Straight-line walkability, for path smoothing or "can I just charge?"
bool clear = mesh.IsStraightPathClear(from, to, stepLength: 0.5f, tolerance: 0.5f);

// A* over triangle centroids.
var corners = new List<Vector3>();
if (mesh.FindPath(start, goal, corners, snapDistance: 2f)) { }

foreach (var (a, b, c) in mesh.EnumerateTriangles())
    Gizmos.DrawLine(a, b, Color.Lime);
```

`NavMesh.Build` takes raw geometry, so the source can be a level mesh, a hand-
authored walkable plane, or a grid you triangulate yourself. There is no
automatic bake — you supply the vertices and indices.

Visualising the mesh with `EnumerateTriangles` and `Gizmos` is the fastest way to
debug "why won't my agent go there".

## NavMeshAgent

```csharp
var agent = actor.AddComponent<NavMeshAgent>();
agent.NavMesh              = NavMesh.Active;
agent.Speed                = 3.5f;
agent.AngularSpeed         = 540f;      // degrees/second
agent.StoppingDistance     = 0.4f;
agent.CornerTolerance      = 0.3f;
agent.RepathInterval       = 0.5f;
agent.SnapDistance         = 2f;        // how far off-mesh a request may start
agent.FaceMovementDirection = true;
agent.DriveCharacter       = true;      // route movement through a Character instead of moving the transform
```

```csharp
bool ok = agent.SetDestination(target);
agent.SetPath(precomputedCorners);
agent.ResetPath();
agent.IsStopped = true;

agent.Path;                    // IReadOnlyList<Vector3>
agent.CurrentCorner;
agent.Destination;             // Vector3?
agent.RemainingDistance;
agent.HasReachedDestination;
agent.PathFailed;

agent.DestinationReached.Add(() => Debug.WriteLine("arrived"));
agent.PathfindingFailed.Add(() => Debug.WriteLine("no path"));
```

Set `DriveCharacter = true` when the actor is a
[`Character`](22-gameplay-framework.md#character) — the agent then feeds
`AddMovementInput` instead of teleporting the transform, so the character's
physics, gravity and animation stay in charge.

## AIController

```csharp
var ai = new AIController
{
    SightRadius        = 20f,
    FieldOfView        = 110f,      // full cone angle, degrees
    RequireLineOfSight = true,
    EyeHeight          = 1.6f,
    BrainEnabled       = true,
};

var enemy = new Character("Grunt");
scene.AddActor(enemy);
scene.AddActor(ai);
ai.Possess(enemy);                            // adds a NavMeshAgent to the pawn

ai.BehaviorTree = new BehaviorTree(root, ai.Blackboard, ai);
```

```csharp
ai.Blackboard;         // the tree's memory
ai.NavAgent;           // the possessed pawn's NavMeshAgent
ai.CanSee(target);     // radius + FOV + optional line-of-sight raycast
ai.MoveTo(position);
ai.MoveTo(actor);
ai.StopMovement();
ai.BrainEnabled = false;    // freeze the AI without destroying it
```

`AIController.Update` ticks `BehaviorTree` when `BrainEnabled` is true. Possession
sets up `NavAgent`; un-possession tears it down.

`CanSee` is the perception primitive: distance against `SightRadius`, angle
against `FieldOfView`, then an optional `PhysicsSystem3D.Raycast` from
`EyeHeight`. Wire it into a `Condition` decorator so a behaviour interrupts the
moment sight breaks.

## A complete enemy

```csharp
static class BB
{
    public const string Target   = "target";
    public const string Home     = "home";
    public const string Waypoint = "waypoint";
}

public static AIController SpawnGrunt(Scene scene, Vector3 position, Vector3[] patrol)
{
    var pawn = new Character("Grunt") { WalkSpeed = 3.5f, OrientToMovement = true };
    pawn.AddComponent<Transform3D>().Position = position;
    scene.AddActor(pawn);

    var ai = new AIController { SightRadius = 18f, FieldOfView = 100f };
    scene.AddActor(ai);
    ai.Possess(pawn);

    ai.Blackboard.Set(BB.Home, position);
    int wp = 0;

    var root = new Selector(
        // Chase whatever we can see.
        new Condition(
            c => c.Controller?.CanSee(c.Blackboard.Get<Actor>(BB.Target)) == true,
            new Sequence(
                new MoveToNode(BB.Target, acceptanceRadius: 2f),
                new Cooldown(
                    new ActionNode(c => Debug.WriteLine("swing!"), "Attack"),
                    seconds: 1.0f))),

        // Otherwise patrol.
        new Sequence(
            new ActionNode(c =>
            {
                c.Blackboard.Set(BB.Waypoint, patrol[wp]);
                wp = (wp + 1) % patrol.Length;
            }, "NextWaypoint"),
            new MoveToNode(BB.Waypoint, 1f),
            new WaitNode(1.5f)));

    ai.BehaviorTree = new BehaviorTree(root, ai.Blackboard, ai);
    return ai;
}
```

Feed it a target from your perception or damage code:

```csharp
ai.Blackboard.Set(BB.Target, player);
```

## Debugging AI

```csharp
// The current path
for (int i = 1; i < agent.Path.Count; i++)
    Gizmos.DrawLine(agent.Path[i - 1], agent.Path[i], Color.Yellow);

// The sight cone
Gizmos.DrawCircle(eyePos, ai.SightRadius, 32, ai.CanSee(target) ? Color.Red : Color.Gray);

// What the tree decided
Debug.WriteLine($"{ai.BehaviorTree?.Root.Name}: {ai.BehaviorTree?.LastStatus}");
```

`BehaviorNode.LastStatus` on each node tells you exactly which branch ran —
walk the tree once a second and log it while you are tuning.
