# 9. UI

Namespaces: `SexyBiscuit.Engine.UI`, `.UI.Widgets`, `.UI.Layout`

An immediate-ish retained widget tree drawn with `SpriteBatch`. A `Canvas` is a
`Component`; widgets live inside it.

```
Actor
└── Canvas (Component)
    └── Widget[]                 Children
        └── Widget[]             nested children
```

---

## Canvas

```csharp
var uiActor = new Actor("HUD");
var canvas  = uiActor.AddComponent<Canvas>();
canvas.ReferenceResolution = new Vector2(1920, 1080);
canvas.ScaleMode           = CanvasScaleMode.ScaleWithScreen;
canvas.Font                = Content.Load<SpriteFont>("Fonts/ui");
scene.AddActor(uiActor, "ui");
```

### Scale modes

| Mode | Behaviour |
|---|---|
| `PixelPerfect` | Identity matrix. One canvas pixel = one screen pixel. |
| `ScaleWithScreen` | **Default.** Non-uniform scale per axis; fills the viewport, distorts aspect. |
| `ConstantSize` | Uniform scale using the smaller axis. Content is never clipped; letterboxes. |

```csharp
Matrix ui = canvas.GetScaleMatrix(GraphicsDevice);
```

Pass that matrix to `SpriteBatch.Begin(transformMatrix: ui)` — see
[Drawing the canvas](#drawing-the-canvas) below.

### Adding widgets

```csharp
var label = canvas.AddWidget<Label>();        // T : Widget, new()
canvas.AddWidget(existingWidget);
canvas.RemoveWidget(widget);
```

`AddWidget` sets `widget.Canvas` and clears `widget.Parent` — top-level widgets
only. Nest with `widget.AddChild(child)`.

### Input

`Canvas.Update` reads `Mouse.GetState()` **directly**, not through
`InputManager`. It dispatches to children in reverse order (last added = topmost
= first to see the event) and tracks left-button just-pressed itself.

Consequences:

- UI input works even if you never touch `InputManager`.
- Mouse position is in **raw screen pixels**, and is *not* transformed by
  `GetScaleMatrix`. With `ScaleWithScreen` at a viewport that differs from
  `ReferenceResolution`, hit-testing and rendering disagree. Either use
  `PixelPerfect`, or set `ReferenceResolution` to the actual back-buffer size.
- A click is delivered to every widget under the cursor, not just the topmost —
  there is no event consumption. Avoid overlapping interactive widgets.

## Widget

```csharp
public abstract class Widget
{
    public string  Name;
    public bool    Visible      = true;
    public bool    Interactable = true;

    public Vector2 Position;                  // relative to the resolved anchor
    public Vector2 Size          = (100, 30);
    public Color   Tint          = Color.White;
    public float   Opacity       = 1f;

    public Vector2 AnchorMin     = (0, 0);    // normalised point in the parent rect
    public Vector2 AnchorMax     = (0, 0);
    public Vector2 AnchorOffset;              // pixels, after the anchor resolves

    public Canvas? Canvas;
    public Widget? Parent;
    public List<Widget> Children;
    public Rectangle Bounds { get; }          // computed screen rect

    public event Action? OnClick;
    public event Action? OnHoverEnter;
    public event Action? OnHoverExit;

    public void AddChild(Widget child);
    public void RemoveChild(Widget child);
    public bool ContainsPoint(Vector2 screenPoint);
    public virtual void Update(float dt);
    public virtual void HandleInput(Vector2 mousePos, bool mouseDown, bool mouseJustPressed);
    public abstract void Draw(SpriteBatch sb, SpriteFont? font);
}
```

### How `Bounds` resolves — Verified

```
if Parent != null:
    origin = Parent.Bounds.TopLeft + Parent.Bounds.Size * AnchorMin + AnchorOffset
else:
    origin = AnchorOffset

Bounds = Rectangle(origin + Position, Size)
```

Two things follow:

1. **`Bounds` ignores `AnchorMax`.** Stretch-to-fill is implemented separately,
   by `AnchorLayout.Apply` — see [Layout helpers](#layout-helpers). Until you
   call it, a widget's `Size` is literal no matter what `AnchorMax` says.
2. **A root widget's origin is `AnchorOffset`, not the screen.** For a root
   widget, `Position` and `AnchorOffset` add up to the same thing; use whichever
   you prefer, but pick one.
3. **`Bounds` is recomputed on every access**, walking up the parent chain each
   time. Deep widget trees redraw at O(depth) per widget per frame. Keep the
   hierarchy shallow.

Anchoring a child to the bottom-right of its parent:

```csharp
child.AnchorMin    = new Vector2(1f, 1f);
child.AnchorOffset = new Vector2(-child.Size.X - 12, -child.Size.Y - 12);
child.Position     = Vector2.Zero;
```

### Events

`OnClick` fires on the frame the left button goes down while the cursor is
inside `Bounds` and `Interactable` is true. `OnHoverEnter` / `OnHoverExit` fire
on the transition. `IsHovered` is a `protected bool` for subclasses.

```csharp
button.OnClick      += () => sceneManager.LoadScene("Scenes/Level1");
button.OnHoverEnter += () => audio.PlayOneShot("Assets/Audio/hover.wav");
```

## Widgets

### Label

```csharp
var label = canvas.AddWidget<Label>();
label.Text      = "SCORE 0";
label.TextColor = Color.White;
label.Alignment = TextAlignment.Center;    // Left | Center | Right
label.WordWrap  = false;
label.Position  = new Vector2(0, 40);
label.Size      = new Vector2(1920, 48);
```

**A `Label` draws nothing when `Canvas.Font` is null** — it returns silently.
`FontSize` is informational only; `SpriteFont` is pre-baked at one size.

If `Size == Vector2.Zero`, the label auto-sizes to the measured text on its first
draw.

### Button

```csharp
var btn = canvas.AddWidget<Button>();
btn.Text            = "Start Game";
btn.TextColor       = Color.White;
btn.Size            = new Vector2(320, 56);
btn.NormalTexture   = Assets.Load<Texture2D>("Assets/UI/btn.png");
btn.HoverTexture    = Assets.Load<Texture2D>("Assets/UI/btn_hover.png");
btn.PressedTexture  = Assets.Load<Texture2D>("Assets/UI/btn_press.png");
btn.DisabledTexture = Assets.Load<Texture2D>("Assets/UI/btn_off.png");
btn.OnClick        += StartGame;

btn.Interactable = false;      // → State becomes Disabled
ButtonState state = btn.State; // Normal | Hover | Pressed | Disabled
```

**A `Button` with no textures draws only its text.** There is no default
background fill. Supply at least `NormalTexture`, or wrap the button in a
`Panel` that has one, or generate a 1×1 white texture and tint it:

```csharp
var white = new Texture2D(GraphicsDevice, 1, 1);
white.SetData(new[] { Color.White });

btn.NormalTexture = white;
btn.Tint          = new Color(60, 60, 90);
```

### Panel

```csharp
var panel = canvas.AddWidget<Panel>();
panel.Position          = new Vector2(760, 400);
panel.Size              = new Vector2(400, 400);
panel.BackgroundColor   = new Color(0, 0, 0, 160);
panel.BackgroundTexture = white;                  // required to see the colour
panel.IsNinePatch       = false;
panel.NinePatchBorder   = 8;
panel.Padding           = 12f;
panel.LayoutMode        = PanelLayoutMode.Vertical;   // None | Vertical | Horizontal
panel.AddChild(btn);
```

**`BackgroundColor` is only used as a tint for `BackgroundTexture`.** With no
texture, the panel draws nothing but its children.

`LayoutMode` runs `ApplyLayout()` at the start of every `Draw`, stacking children
along the axis with `Padding` between them.

### Image

```csharp
var img = canvas.AddWidget<Image>();
img.Texture         = Assets.Load<Texture2D>("Assets/UI/portrait.png");
img.Tint            = Color.White;
img.IsNinePatch     = true;
img.NinePatchBorder = 12;
```

`Image.DrawNinePatch` is `static` and reused by `Panel`.

### ProgressBar

```csharp
var hp = canvas.AddWidget<ProgressBar>();
hp.MaxValue        = 100f;
hp.Value           = 73f;                        // clamped to 0..MaxValue
hp.Direction       = FillDirection.LeftToRight;  // also RightToLeft, BottomToTop, TopToBottom
hp.BackgroundColor = Color.DarkGray;
hp.FillColor       = Color.Green;
hp.BackgroundTexture = white;
hp.FillTexture       = white;
```

Like `Panel`, it needs textures to render its colours.

### Slider

```csharp
var vol = canvas.AddWidget<Slider>();
vol.MinValue   = 0f;
vol.MaxValue   = 1f;
vol.Value      = 0.8f;
vol.Step       = 0.05f;      // 0 = continuous
vol.Horizontal = true;
vol.ThumbSize  = new Vector2(20, 24);
vol.TrackTexture = white;
vol.ThumbTexture = white;
vol.OnValueChanged += v => SBEngine.Instance.Audio.Master.Volume = v;
```

Dragging is handled in `HandleInput` while the mouse is held.

### TextInput

```csharp
var name = canvas.AddWidget<TextInput>();
name.Placeholder      = "Player name";
name.MaxLength        = 24;
name.BackgroundColor  = new Color(30, 30, 30);
name.TextColor        = Color.White;
name.PlaceholderColor = Color.Gray;
name.BorderColor      = Color.Gray;
name.FocusBorderColor = Color.CornflowerBlue;
name.OnTextChanged   += t => { };
name.OnSubmit        += t => Join(t);       // fires on Enter
bool focused = name.IsFocused;              // set by clicking the field
```

`TextInput` draws its own background and border through the `FillRect` /
`StrokeRect` helpers, so it is visible with no assets.

### Checkbox and Toggle

```csharp
var cb = canvas.AddWidget<Checkbox>();
cb.Text      = "Fullscreen";
cb.IsChecked = false;
cb.BoxSize   = 20;
cb.LabelGap  = 8f;
cb.CheckedChanged.Add(v => SetFullscreen(v));
```

`Toggle : Checkbox` adds a `Group` for radio-button behaviour, where selecting
one member clears the others.

### Dropdown

```csharp
var dd = canvas.AddWidget<Dropdown>();
dd.SetOptions("Low", "Medium", "High", "Ultra");
dd.SelectedIndex  = 2;
dd.Placeholder    = "Quality…";
dd.RowHeight      = 26;
dd.MaxVisibleRows = 8;
dd.SelectionChanged.Add(i => ApplyQuality(i));

string text = dd.SelectedText;
dd.Collapse();
```

### ScrollView

```csharp
var sv = canvas.AddWidget<ScrollView>();
sv.Size             = new Vector2(360, 400);
sv.ScrollVertical   = true;
sv.ScrollHorizontal = false;
sv.WheelStep        = 48f;
sv.MomentumDamping  = 0.06f;      // flick-scroll inertia
sv.ShowScrollbar    = true;

foreach (var row in rows) sv.AddChild(row);
sv.LayoutVertically(gap: 4f, padding: 4f);   // stacks children and measures content
sv.ScrollToTop();
sv.ScrollToBottom();
```

Call `LayoutVertically` or `MeasureContent()` after changing the children, or
`ContentSize` — and therefore the scroll range — stays stale.

### TabView

```csharp
var tabs = canvas.AddWidget<TabView>();
tabs.Size         = new Vector2(560, 380);
tabs.TabBarHeight = 30;

tabs.AddPage("Audio", audioPanel);
tabs.AddPage("Video", videoPanel);
tabs.AddPage("Input", inputPanel);

tabs.SelectedChanged.Add(i => Debug.WriteLine($"tab {i}"));
tabs.SelectedIndex = 0;
TabPage? page     = tabs.SelectedPage;
Rectangle content = tabs.ContentBounds;
```

`TabPage` carries `Title`, `Content` and `Enabled`.

> The newer widgets broadcast through [`SBEvent`](22-gameplay-framework.md#sbevent)
> rather than C# `event`s, so subscribe with `.Add(handler)` and unsubscribe with
> `.Remove(handler)`. The older ones (`Button.OnClick`, `Slider.OnValueChanged`,
> `TextInput.OnSubmit`) are still plain `event`s using `+=`.

## Which widgets need textures

`Widget` exposes `protected static FillRect(sb, rect, colour)` and
`StrokeRect(sb, rect, colour, thickness)`, backed by a shared 1×1 white pixel
created on first use. Widgets written against those helpers are visible with no
assets; the older ones are not.

| Widget | Self-draws? | Silent when |
|---|---|---|
| `Label` | — | `Canvas.Font` is null |
| `Button` | ❌ | no `NormalTexture` — draws only its text |
| `Panel` | ❌ | no `BackgroundTexture`; `BackgroundColor` is only a tint for it |
| `Image` | ❌ | no `Texture` |
| `Slider` | ❌ | no `TrackTexture` / `ThumbTexture` |
| `ProgressBar` | ✅ | — |
| `TextInput` | ✅ | — |
| `Checkbox` / `Toggle` | ✅ | — |
| `Dropdown` | ✅ | — |
| `ScrollView` | ✅ | — |
| `TabView` | ✅ | — |

A 1×1 white texture covers the first five:

```csharp
var white = new Texture2D(GraphicsDevice, 1, 1);
white.SetData(new[] { Color.White });

button.NormalTexture    = white;
button.Tint             = new Color(52, 58, 82);
panel.BackgroundTexture = white;
```

Two more silent failures that apply to every widget: `Visible = false` or
`Opacity = 0`, and a zero `Size` — only `Label` auto-sizes to its text.

## Layout helpers

`SexyBiscuit.Engine.UI.Layout` — utilities you call, not components.

```csharp
var stack = new StackLayout
{
    Orientation = StackOrientation.Vertical,
    Gap         = 8f,
    Padding     = 12f,
};
stack.Apply(panel);          // repositions panel.Children
```

```csharp
var grid = new GridLayout
{
    Columns    = 4,
    CellWidth  = 96,
    CellHeight = 96,
    GapX = 6, GapY = 6,
    Padding = 8,
};
grid.Apply(inventoryPanel);
```

`AnchorLayout` is where `AnchorMax` finally matters. It rewrites a child's
`Position` and `Size` from its anchor rectangle:

```csharp
AnchorLayout.Apply(child, parent);   // resolve one child's anchor
AnchorLayout.ApplyAll(parent);       // every direct child of parent
```

When `AnchorMax.X > AnchorMin.X` the child is **stretched** horizontally to span
that fraction of the parent; same for Y. Otherwise its own `Size` is kept.

```csharp
// A header bar pinned across the full width of its parent, 64px tall:
header.AnchorMin    = new Vector2(0f, 0f);
header.AnchorMax    = new Vector2(1f, 0f);
header.AnchorOffset = Vector2.Zero;
header.Size         = new Vector2(0, 64);      // width will be overwritten
AnchorLayout.Apply(header, parentPanel);
```

All three helpers are **one-shot**: call them after adding or resizing children,
and again on window resize. `ApplyAll` is not recursive despite the name — it
covers direct children only. Only `Panel.LayoutMode` re-runs automatically, at
the start of each `Panel.Draw`.

## Themes

Skin widgets from JSON instead of assigning properties one by one.

```json
{
  "Button": {
    "normalTexture":  "Assets/UI/btn.png",
    "hoverTexture":   "Assets/UI/btn_hover.png",
    "pressedTexture": "Assets/UI/btn_press.png",
    "textColor":      "#FFFFFF",
    "fontSize":       18
  },
  "Panel": {
    "backgroundColor": "#000000B4"
  },
  "Label": {
    "textColor": "#E8E8F0"
  }
}
```

```csharp
Theme.Load("Assets/UI/theme.json");
Theme.Apply(myButton);            // uses Theme.Current
Theme.Current.ApplyTo(myPanel);
WidgetStyle? style = Theme.Current.GetStyle(myButton);
```

Styles are keyed by **type name** and resolved by walking up the widget's base
class chain — a `Button` with no `"Button"` entry falls back to a `"Widget"`
entry. Colours parse as `#RRGGBB` or `#RRGGBBAA`.

`Theme.Apply` must be called per widget; it is not automatic on creation.

## Drawing the canvas

`Canvas.Draw` runs inside `Actor.InternalDraw`, i.e. inside whatever
`SpriteBatch` the scene pass opened — which is camera-transformed. UI would
scroll with the world. Draw the UI layer separately:

```csharp
protected override void Draw(GameTime gameTime)
{
    GraphicsDevice.Clear(Config.ClearColour);
    var scene = SceneManager.ActiveScene;
    if (scene == null) return;

    var uiLayer = scene.GetLayer("ui");

    // 1. World pass, through the camera, with UI hidden.
    if (uiLayer != null) uiLayer.Visible = false;
    Renderer2D.RenderScene(SpriteBatch, scene, _camera);
    if (uiLayer != null) uiLayer.Visible = true;

    // 2. UI pass, in screen space.
    SpriteBatch.Begin(
        sortMode:        SpriteSortMode.Deferred,
        blendState:      BlendState.AlphaBlend,
        samplerState:    SamplerState.LinearClamp,
        transformMatrix: _canvas?.GetScaleMatrix(GraphicsDevice));
    uiLayer?.Draw(SpriteBatch);
    SpriteBatch.End();
}
```

Use `LinearClamp` for UI even in a pixel-art game — scaled UI textures alias
badly under `PointClamp` unless your scale factor is an integer.

## Fonts

`Canvas.Font` is a MonoGame `SpriteFont`. **`AssetManager` cannot load
`SpriteFont`** — it handles `Texture2D`, `SoundEffect`, `string` and `byte[]`
only. Use the MonoGame content pipeline:

1. Add a `.spritefont` description to your MGCB project.
2. Build it into `Content/`.
3. `canvas.Font = Content.Load<SpriteFont>("Fonts/ui");`

`FontStashSharp.MonoGame` is referenced by the engine project for runtime TTF
loading, but no engine code uses it. If you want runtime TTF, wire FontStashSharp
yourself and render text in a custom `Widget` subclass.

## World-space UI

`WorldCanvas` puts a canvas at an actor's world position — health bars,
nameplates, damage numbers.

```csharp
var wc = actor.AddComponent<WorldCanvas>();
wc.Offset            = new Vector2(0, -48);
wc.Scale             = 0.75f;
wc.BillboardToCamera = true;

var bar = wc.Canvas.AddWidget<ProgressBar>();
bar.Size = new Vector2(64, 8);
```

`wc.Canvas` is a plain `Canvas` object owned by the component (not attached as a
separate component). It draws in the world pass, so it moves with the camera —
which is exactly what you want here.

## A complete pause menu

```csharp
public sealed class PauseMenu
{
    private readonly Canvas _canvas;
    private readonly Panel  _root;
    private bool _open;

    public PauseMenu(Scene scene, SpriteFont font, Texture2D white)
    {
        var actor = new Actor("PauseMenu");
        _canvas = actor.AddComponent<Canvas>();
        _canvas.Font = font;
        _canvas.ReferenceResolution = new Vector2(1920, 1080);
        scene.AddActor(actor, "ui");

        _root = _canvas.AddWidget<Panel>();
        _root.Position          = new Vector2(710, 340);
        _root.Size              = new Vector2(500, 400);
        _root.BackgroundTexture = white;
        _root.BackgroundColor   = new Color(10, 10, 20, 220);
        _root.LayoutMode        = PanelLayoutMode.Vertical;
        _root.Padding           = 16f;
        _root.Visible           = false;

        AddButton("Resume",  white, font, () => Toggle());
        AddButton("Options", white, font, () => { });
        AddButton("Quit",    white, font, () => SBEngine.Instance.Exit());
    }

    private void AddButton(string text, Texture2D white, SpriteFont font, Action onClick)
    {
        var b = new Button
        {
            Text          = text,
            TextColor     = Color.White,
            Size          = new Vector2(468, 64),
            NormalTexture = white,
            Tint          = new Color(45, 45, 70),
        };
        b.OnClick += onClick;
        _root.AddChild(b);
    }

    public void Toggle()
    {
        _open = !_open;
        _root.Visible = _open;

        var scene = SBEngine.Instance.SceneManager.ActiveScene!;
        foreach (var layer in scene.Layers)
            if (layer.Name != "ui")
                layer.Active = !_open;
    }
}
```
