# wiki — the reference, one page per topic

Thirty pages, about 110k tokens in all. Read the one page for the topic (the index is `README.md`
here), never the folder. `20-api-index.md` is the API list; `21-gotchas.md` is the ledger of
things that shipped through a green board; `25-ai-assistant-mcp.md` carries the generated tool
table; `11-scripting.md` is the scripting contract both engines implement.

Changing behaviour means changing the page (`CONTRIBUTING.md`). Where the root `README.md` and a
wiki page disagree, the wiki describes what the code does today.
